# WorkoutApp for AltStore Classic

WorkoutApp helps you plan gym sessions and follow them in practice mode. Create
sessions with exercises, sets, weights, reps, and rest times; check off sets as
you train; and import or export plans as JSON. Workout data stays on your
device.

## Install

In AltStore Classic, open **Sources**, tap **+**, and add:

`https://raw.githubusercontent.com/adrienpessu/WorkoutApp-AltStore/main/source.json`

The source provides the unsigned IPA. AltStore Classic signs it with the
installer's Apple Account. Free-account installations need refreshing every
seven days and are subject to Apple's three active sideloaded app limit.

This Classic build includes the iPhone and iPad app. It omits the Live Activity
widget and Apple Watch app.
